# 把八本书读成一套方法

现已升级为分类学习中心：首页选择分类，现有八本书、168课归入「金融学习卡片」。旧课程链接、原学习记录及每日Notion推送保持兼容。Notion目录为「学习日记 → 学习分类 → 金融学习卡片」；分类页引用原课程与书库，不移动正式进度页。新增领域的实施与记录隔离规则见 [分类与扩展](docs/分类与扩展.md)。

八本书的联合学习工程：24周、168个学习日，每天以原文精读、讲解、八题自测和作业组织约30—45分钟。实际学习速度不同，可以顺延，不用时长代替掌握。

## 交付内容

- 168课、96张新概念卡、24案例、24练习、24复盘；每日1344题，另有六阶段120题（抽样重测核心题，不是120道全新题）与结业项目。
- 201个章/年度信单位覆盖：66项核心选读，135项专题、历史或年代延伸。可下载逐项覆盖表；不是宣称每段文字均在主课中逐字讲授。
- Notion“168天课程全集（预习与补课）”含全课正文、私有原文节选、PNG图解、折叠答案和作业；每天正式推进页另建。
- 私有原文书库：120个全文分卷，SHA-256回读一致；20个原版图文附件，保留PDF/EPUB/MOBI原图。手机登录自己的Notion访问；公开仓库不收录原书或个人笔记。
- 手机网页：今日、计划、展开式框架、全文教学搜索、书籍与章节导读、错题、3/7/21天复习、阶段测验、字号、主题、记录导出与恢复。三项交互演示用于理解复利、折现和风险数量。

## 使用与完成

每日先读原文，再学解释，闭卷回答8题并完成练习。至少自评6题正确且作业达到要求后记录完成。自评不是专家认证；阶段考试至少16/20，结业评分至少80/100，有重大来源或计算错误须修订。延伸章节可选，不挤入每日时间。

Notion正式日课的“已完成”是唯一云端推进依据。预习全集与网页本机记录不推动云端进度。漏学停留当前课，完成后次日推进，168天后停止。网页记录可以导出JSON，在另一设备恢复；不要在公共电脑保存私人答案。

## 本地运行与验证

Node.js22：`npm ci`、`npm run check`、`npm test`、`npm run build`、`npm run dev`，打开 http://127.0.0.1:4188/ 。`dist/`可重建。课程与章节CSV从同一份结构化内容生成。

课程数据在`content/`，生成器在`scripts/`；所有168课均由完整教学数据生成，不再保留第8天大纲占位。`release.json`锁定内容哈希，任何课程变更都会阻止正式推送，重新完成验收后才能封版。修改后需重新同步受影响Notion课程，不能覆盖用户笔记或盲目重建页面。

原文定位为净化后的提取文本行号，不是假装PDF页码。PDF表格、排版、OCR疑点以原版附件为准。巴菲特PDF末封为2023年度信（2024年落款）；段永平文件实际为孙力科编著《投资的本质》与《段永平传》。严格区分本人发言、编者与传记。

## 云端推送与故障处理

GitHub Actions北京时间07:00准备，07:30和08:15补检。仓库变量`COURSE_START_DATE`指定开课日，`ENABLE_NOTION_PUSH`为正式开关；Secrets保存`NOTION_TOKEN`和`NOTION_PARENT_ID`。联调完成后启用，电脑关机也能执行。调度不是精确闹钟，平台可能延迟或停用：[GitHub官方说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)。

手动运行Daily Notion工作流的`check`验证访问，`sample`复用试学页，`push`补发正式课程。重复运行检查当前课并回读正文和答案；不完整、缺号、重复、权限失效会停止，不跳课。API限流会重试；创建结果未知时回读再重跑，不盲目重复POST。

每周心跳检查每日工作流状态，恢复因不活跃被停用的工作流并提交公开时间戳；不覆盖用户主动停用。平台整体停用或账户问题仍需人工处理，Actions失败会按GitHub账号的通知设置提醒，不承诺手机系统通知必达。

本机凭据为`.local/notion-token.dpapi`，由当前Windows用户加密；云端仅用GitHub Secrets。原文附件与个人记录不入Git。其他机器需自行授权，禁止把令牌粘入源码或Issue。
